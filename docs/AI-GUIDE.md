# 給 AI 助手的修改指南

這份文件說明如何協助使用者修改「顏料庫存」系統的資料或程式。

## 一、修改資料（最常見）

使用者會從系統的「設定 → 匯出 md 檔」取得一份 Markdown，請你修改後交還，再由使用者匯入。

### 可以匯入的部分

只有「顏料與輔助劑」表格，以及「品牌與系列」表格中新增的品牌、系列會被讀取。「計畫」一節只供閱讀，修改它不會有任何效果。

### 表格欄位

| 欄位 | 說明 |
| --- | --- |
| ID | 系統產生的識別碼。**既有的列不要改**；新增的列留空 |
| 類別 | 顏料、輔助劑 |
| 品牌 / 系列 | 文字。填了系統裡沒有的名稱，匯入時會自動建立 |
| 色碼 / 色名 | 至少要有一個 |
| 種類 | 顏料：一般漆、對比漆、底漆、保護漆、漬洗漆、特殊漆、效果漆、舊化漆、墨水、地形漆、濾鏡漆、顏料粉。輔助劑：稀釋液、介質、緩乾劑、Flow、去漆液、洗筆液、清潔劑 |
| 漆性 | 水性壓克力、油畫顏料、琺瑯漆、硝基漆、其他 |
| 光澤 | 消光、半光、亮光、金屬、其他 |
| 容量ml | 數字 |
| 數量 | 整數（罐數） |
| 狀態 | 滿、一半、快用完、用完。填「刪除」代表刪掉這一列 |
| 擁有 | 是、否。「否」代表還沒買，會出現在購物清單 |
| 色票 | `#RRGGBB`，可留空 |
| 備註 | 文字，不能含有 `|` 字元 |

### 規則

1. 保留檔案開頭的 `<!-- paint-inventory-md v1 -->`。
2. 不要更動既有列的 ID。
3. 要刪除資料，把該列的「狀態」改成「刪除」。直接移除整列不會刪除資料。
4. 新增的列必須接在表格內，不能與表格之間有空行。
5. 選項欄位只能填上面列出的字詞，其他字詞會被當成空白。
6. 圖片不在 md 裡，無法透過 md 修改。

匯入時系統會先顯示「新增／修改／刪除幾項」讓使用者確認，確認後才寫入。

## 二、修改計畫、塗層等其他資料

請使用者改用「設定 → 下載備份檔」取得 JSON。結構與資料庫相同（見 `supabase/schema.sql`）：

```
brands → series
paints（brand_id、series_id）
project_categories
projects（category_id）
  project_paints（project_id、paint_id）
  project_sections（project_id）
    section_layers（section_id，sort 由小到大 = 由下層到上層）
      layer_paints（layer_id、paint_id）
```

修改後由「從備份檔還原」寫回。還原是「相同 id 覆蓋、沒有的新增」，不會刪除資料。新增的列需要自行產生 UUID 作為 id。

## 三、修改程式

- 沒有建置步驟，直接修改檔案即可。
- 要增加種類、漆性、光澤等選項：修改 `js/constants.js`。資料庫欄位是純文字，不需要改資料庫。
- 要增加欄位：先在 Supabase 執行 `alter table`，更新 `supabase/schema.sql`，再修改表單（`js/views-library.js`）與匯出匯入（`js/md.js`）。
- 介面文字一律使用繁體中文。
- 修改後用 `?demo` 模式在本機測試。
